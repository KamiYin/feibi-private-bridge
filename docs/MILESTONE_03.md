# 第三里程碑（0.3.0）：文字／图片／文件完整版

日期：2026-10-29。此次是项目的**第三个里程碑**：在第二里程碑长期文字版之上，形成文字、普通图片与文件双向传递的完整版本。第二里程碑的技术纪要与证据保留原编号，不改写为本次新增成果。

## 1. 本版新增与扩展

- **文字／图片／文件**：图片返回 MCP image，文件返回 resource/blob；大文件按 offset/length 分段读取，同一原件只下载一次。混合消息保留支持项，并提供不支持项的类型元数据。
- **主动联系本人**：使用最近真实来信的 contextToken 主动发送文字，不开放任意收件人；上下文是否过期由微信服务端决定。
- **多次回复**：同一请求可先发进度再发最终结果，每次发送独立幂等；显式 handled 将处理完成与发送结果分开，unknown 不自动重发。
- **媒体并发与复用**：媒体 MCP 并发 4，最多两份附件并行准备并保留顺序，复用连接、下载与上传结果；减少不必要的状态复制和保存。

工具定义和状态语义见 [架构](ARCHITECTURE.md)，性能实现与证据见 [性能](PERFORMANCE.md)。

## 2. 从第二里程碑沿用的关键能力

- **活跃会话主动查询 pending 接续**：无需只等通知；完整短文字可从 Events/pending 直接处理，减少一次 get 往返。
- **事件通知兜底与晚到去重**：主动读取与通知协调；已经被平台接受的事件不能撤回，晚到事件仍需去重，不能重复回复。
- **后台运行与加密恢复**：当前用户隐藏计划任务、DPAPI 保护、原登录与订阅恢复、跨重启 pending 和未知发送状态恢复。
- **文字引用**：沿用有限加密引用缓存和来源 ID 兼容。

这些能力在 [第二里程碑技术纪要](MILESTONE_02.md) 已有实现和验收记录，本版继承而非首次引入。其历史测量保留在 [第二里程碑证据归档](MILESTONE_02_EVIDENCE.md)，不当作 0.3.0 新增性能结果。

## 3. 本版验证与重启恢复证据

当前公开记录包括媒体实现的定向测试、图片与多种文件基础链路，以及 Windows 启动适配验证。2026-10-29 实际 Windows 重启后，原计划任务自动启动，本人连接与原订阅恢复，MCP 状态调用成功；该次重启后未另发测试消息，完整聊天往返未单独验收。

主动发送与多次回复的新语义仍需插件刷新后的自然交互确认；GIF 动态展示尚未通过。0.2.0 的 191 项历史测试不是 0.3.0 全量测试结果。本版已执行的测试、范围和限制以 [验证记录](VALIDATION.md) 为准。
