# 问题与修复

| 现象 | 已知原因/证据 | 当前处理 |
| --- | --- | --- |
| 控制面长期等响应 | wait_response、h2、复用连接；不能确定最底层网络根因 | 自身 deadline 后更新实际连接池，保留正常空响应和父取消 |
| .1 超时计数增长却不换池 | 真实 timeout 包装/分类未覆盖 | .2 修正分类，.3 门槛降一次 |
| 正文已收到但回复仍慢 | 平台排队、模型调度、晚到 Events 与工具往返 | 正文直达，近期读取时有界通知延迟；不保证秒回 |
| 隐藏启动后看不到码 | 显示回执不等于用户实际可见 | 独立可见 QR 窗口，日志宿主保持后台 |
| 空白终端关闭后监督任务退出 | 退出码 0xC000013A；早期判断只看收发进程 | wscript 隐藏入口 + CreateNoWindow；具体触发动作未完全归因 |
| 任务找不到已存凭据 | 打包应用与任务的 LocalAppData 视图不同 | 使用同用户、同一明确目录；不复制原部署凭据到公开项目 |
| 停止后反复启动 | 必须区分操作员停止与异常退出 | 先写 operator-stopped；明确 Resume 才恢复 |
| 关机/崩溃期间发送结果不明 | 无法证明服务端是否接受 | 恢复为 unknown，不自动重发 |
| 引用 not_cached | 无 ID、未缓存、被淘汰或真实解析遗漏 | 外层 svr_id / 内层 msg_id；无损字符串；结构诊断，不猜正文 |
| 引用只有 title | 它可能是摘要，不等同完整原文 | 单独保留 title，不冒称完整正文 |
| 长文字部分失败 | 后续分段不可安全整体重放 | 停止余下分段，结果 unknown |
| 密钥被撤销/登录失效 | 服务端授权边界 | 正常失败并重新授权，不能靠本地延期修复 |
| 设备 connected 但命令没执行 | 执行器连接状态与实际执行不同 | 以具体调用结果为准，结果不明先查状态再重试 |

初期 QR POST 405 的一次同源 GET 兼容仍保留，仅适用于无旧凭据的初次明确 405；来源根因未独立确定。完整历史见阶段纪要与时间线。
